## 🚀 Getting started with your first project

The first time you open UGC-dashboard, the application guides you through the setup. You need to connect your API keys if you want to use the OpenAI features. 

1. Locate the Settings menu in the top right corner.
2. Select "API Keys."
3. Enter your OpenAI credentials into the provided fields.
4. Save your changes.

Now, you can start building your first workflow. The main screen shows a blank canvas. This is where you design your content path. 

- Use the sidebar to pick AI blocks. These blocks represent tasks like "generate image," "edit video," or "add voiceover."
- Drag and drop these blocks onto the canvas to create your sequence.
- Connect the blocks with lines to tell the software the order of operations.
- Click the "Run" button at the bottom of the screen to start the process.

The AI will process your inputs based on the sequence you created. You can watch the progress in the status window located at the bottom of the dashboard. When the task finishes, the software notifies you, and you can download your visual assets directly to your computer.

## 💡 Troubleshooting common issues

If you encounter problems, check these items first.

**The application fails to open**
Check that you have a stable internet connection. The application occasionally verifies licenses when it starts. If it still fails, restart your computer and try opening the shortcut again.

**The output files look low quality**
Check your API settings. High-quality generation sometimes requires specific model settings. Ensure you have selected the "High Definition" or "Pro" mode in your workflow settings.

**The screen freezes during a task**
AI processes take time. If you have a large workflow or complex AI prompts, the application might seem busy. Wait 60 seconds. If it does not recover, open your Task Manager by pressing Ctrl + Shift + Esc and close the dashboard, then restart it.

**Update notifications**
We update this software regularly to add new features and improve performance. When you open the app, it will check for new versions. If one exists, the app will ask you to visit the download page again. Follow the same steps as the initial installation to update your software.
